## ประมาณการของมหาวิทยาลัย

กองวิเทศสัมพันธ์ มหาวิทยาลัยธรรมศาสตร์ ประเมินค่าครองชีพรายเดือนไว้ดังนี้

| รายการ               | บาทต่อเดือน      |
| -------------------- | ---------------- |
| ที่พัก               | 5,500 ถึง 10,000 |
| อาหาร                | 8,000            |
| การเดินทาง           | 2,500            |
| รวม ถ้าค่าเช่าต่ำสุด | ประมาณ 16,000    |
| รวม ถ้าค่าเช่าสูงสุด | ประมาณ 20,500    |

ค่าเล่าเรียนไม่รวมอยู่ในนี้ ดู [ค่าเล่าเรียน ค่าธรรมเนียม และการขอคืนเงิน](/student-life/money/tuition-and-fees)

นักศึกษาที่พัก TU Dorm ท่าพระจันทร์ใช้เงินน้อยกว่านี้ หน้าที่พักของกองวิเทศสัมพันธ์ระบุไว้ที่ 6,500 ถึง 7,800 บาทต่อเดือน

| รายการ         | บาทต่อเดือน     |
| -------------- | --------------- |
| ห้องพักคู่     | 2,700           |
| ค่าไฟและค่าน้ำ | ประมาณ 300      |
| การเดินทาง     | 500 ถึง 800     |
| อาหาร          | 3,000 ถึง 4,000 |

## ค่าเช่า

TU Dorm ท่าพระจันทร์ค่าเช่าประมาณ 2,700 บาทต่อคนต่อเดือน ห้องเช่าและอพาร์ตเมนต์เอกชนที่กองวิเทศสัมพันธ์รวบรวมไว้ราคาตั้งแต่ประมาณ 4,000 ถึง 17,900 บาทต่อเดือน ดู [การหาที่พัก](/student-life/living-nearby/housing)

## ค่าเดินทาง

| เส้นทาง                     | ค่าโดยสาร (บาท)                  |
| --------------------------- | -------------------------------- |
| เรือด่วนเจ้าพระยาธงส้ม      | 20 ตั้งแต่ 7 เมษายน 2569         |
| รถเมล์ธรรมดา                | 8                                |
| รถเมล์ปรับอากาศ             | 15 ถึง 25                        |
| รถเมล์ทางด่วน 1-9E ไปรังสิต | 27                               |
| MRT สายสีน้ำเงิน            | 17 ถึง 44 ตั้งแต่ 3 กรกฎาคม 2569 |
| รถเวียนธรรมศาสตร์           | ฟรี                              |

[รถเวียนฟรี](/student-life/getting-around/shuttle-bus)ของธรรมศาสตร์วิ่งในสายสถานี MRT สนามไชยและสายปิ่นเกล้า

นักศึกษาสัญชาติไทยที่ลงทะเบียนในแอปทางรัฐจ่ายค่าโดยสาร BTS และ MRT ไม่เกิน 20 บาท นักศึกษาต่างชาติไม่มีสิทธินี้

## ค่าโทรศัพท์

แพ็กเกจซิมเติมเงินต่างกันตามผู้ให้บริการและเปลี่ยนบ่อย ควรเทียบราคาที่ร้านก่อนซื้อ ดู [ซิมการ์ดและ Wi-Fi](/student-life/first-weeks/sim-and-wifi)

## ค่าใช้จ่ายตอนย้ายเข้า

- เงินประกันห้องเช่าเอกชน โดยทั่วไป 1 ถึง 2 เดือนของค่าเช่า ส่วน TU Dorm เรียกเงินประกันประมาณ 2,000 บาทต่อคน
- ค่าเช่าเดือนแรกที่จ่ายล่วงหน้า
- ซิมการ์ดและค่าเติมเงินครั้งแรก
- ค่าธรรมเนียมวีซ่าสำหรับนักศึกษาต่างชาติ ดู [กฎเกี่ยวกับวีซ่าระหว่างเรียน](/student-life/rules-and-rights/visa-rules)

## ประหยัดค่าใช้จ่าย

โรงอาหารและร้านในตลาดถูกกว่าร้านอาหารทั่วไป ดู [ร้านอาหารใกล้ท่าพระจันทร์](/student-life/living-nearby/where-to-eat) และ [ส่วนลดสำหรับนักศึกษา](/student-life/money/student-discounts)
