ปฐมนิเทศเบื้องต้น BIR18 (Pre-Session) จัดขึ้นวันที่ 22 กรกฎาคม 2569 เวลา 08.30 ถึง 15.00 น.
ที่ห้อง ร.102 คณะรัฐศาสตร์ มหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์

กิจกรรมตลอดวันนี้จะช่วยเตรียมความพร้อมให้น้อง ๆ นักศึกษาใหม่สำหรับปีการศึกษาที่กำลังจะมาถึง

## กำหนดการ

| เวลา               | กิจกรรม                                                         |
| ------------------ | --------------------------------------------------------------- |
| 08.30 ถึง 09.00 น. | ลงทะเบียน                                                       |
| 09.00 ถึง 10.30 น. | บรรยายหัวข้อ "College Survival" โดย ดร.วศิน ปั้นทอง             |
| 10.30 ถึง 10.40 น. | พักรับประทานอาหารว่าง                                           |
| 10.40 ถึง 12.10 น. | บรรยายหัวข้อ "Academic Integrity" โดย รศ.ดร.พีระ เจริญวัฒนนุกูล |
| 12.10 ถึง 13.30 น. | พักรับประทานอาหารกลางวัน                                        |
| 13.30 ถึง 15.00 น. | บรรยายหัวข้อ "Etiquette and Netiquette" โดย ดร.ปุรวิชญ์ วัฒนสุข |

กำหนดการอาจมีการเปลี่ยนแปลงตามความเหมาะสม
