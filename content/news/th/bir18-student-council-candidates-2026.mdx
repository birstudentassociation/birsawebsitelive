BIR Student Association (BIRSA) ประกาศรายชื่อผู้สมัครคณะกรรมการนักศึกษา BIR18
อย่างเป็นทางการแล้ว มีผู้สมัคร 6 คน ลงในนามพรรค BIR18 Rising Star

<Notice title="แถลงนโยบาย 19 สิงหาคม 2569">
  ผู้สมัครจะแถลงนโยบายที่ห้อง R.102 เวลา 12.30 ถึง 13.00 น. ฟังให้ครบก่อนไปลงคะแนนวันที่ 24 สิงหาคม
</Notice>

## รายชื่อผู้สมัคร

| ผู้สมัคร                | ตำแหน่งที่ลงสมัคร        |
| ----------------------- | ------------------------ |
| จีรณา แสงสว่าง          | แกนนักศึกษา BIR18        |
| วิชญ์ เอี่ยมวุฒิกร      | ผู้ประสานงานศูนย์รังสิต  |
| พิมพ์มาดา ตังอนุสรณ์สุข | ผู้ประสานงานท่าพระจันทร์ |
| วรัญญา มณีธรรม          | ฝ่ายประชาสัมพันธ์        |
| ตะวันฉาย อุตมงค์        | ฝ่ายกิจกรรม              |
| วิศวกร วงศ์พิภพมงคล     | ฝ่ายวิชาการ              |

## การแถลงนโยบาย

| หัวข้อ  | รายละเอียด                                                 |
| ------- | ---------------------------------------------------------- |
| วันที่  | วันพุธที่ 19 สิงหาคม 2569                                  |
| เวลา    | 12.30 ถึง 13.00 น.                                         |
| สถานที่ | ห้อง R.102 คณะรัฐศาสตร์ มหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์ |

ผู้สมัครจะเล่าภาพที่อยากเห็นของรุ่นและนโยบายที่ตั้งใจทำ นักศึกษาเข้าฟัง ซักถาม
และเสนอความเห็นกับผู้สมัครได้โดยตรง

## ขั้นตอนถัดไป

| วันที่                 | ขั้นตอน         |
| ---------------------- | --------------- |
| 16 ถึง 24 สิงหาคม 2569 | ช่วงเวลาหาเสียง |
| 19 สิงหาคม 2569        | การแถลงนโยบาย   |
